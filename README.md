# Yami Client

A high-performance Fabric client mod for Minecraft 1.21.1 (HvH / 2B2T / Grim).

## Download & Installation

1. Go to the [Releases](https://github.com/FagsDevelopment/Yamipublic/releases) page.
2. Download the latest `Yami-1.1.jar`.
3. Place `Yami-1.1.jar` into your Minecraft 1.21.1 `.minecraft/mods` directory (requires Fabric Loader).
4. Launch Minecraft!

## Requirements

- **Java Runtime Environment (JRE) 21** or newer
- Fabric Loader 0.16+ for Minecraft 1.21.1
